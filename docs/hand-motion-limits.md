# 手部输出的强制运动限制

`flowphi/hand_limits.py` 为骨架预览和 Blender 输出共用的约束层。接触拟合、可达性投影和避碰都不能绕过最终限制。两端仍使用各自的骨架/IK，不能把共用约束等同于几何姿态完全相同。

黄键长条候选评估与交互预览已共用 `flowphi/hand_solver.py` 的整个受限骨架求解器；`ui/pose_preview.py` 仅负责工程、编辑和姿态变更的适配。Blender 蒙皮仍是独立 IK，但共用硬限制。候选评估规则和失败草稿的区别见 [黄键长条整体规划](drag-ribbons.md)。

当前默认值是动画参数，尚未以真人采集数据标定：

| 量 | 硬限制 |
| --- | --- |
| 手腕三维平移 | 工程 `settings.wrist_speed`，缺省 0.9 m/s |
| 手腕旋转 | 4 rad/s |
| 指根旋转 | 8 rad/s |
| 中间及末端指节旋转 | 1.5 rad/s |
| 中间及末端指节活动幅度 | 相对自然姿态沿弯曲轴不超过 ±0.20 rad（约 11.5°），侧弯与轴向扭转为零 |
| 非拇指指根张合 | 食指 ±10°、中指 ±7°、无名指 ±8°、小指 ±12°，均相对放松姿态 |
| 非拇指指根屈伸 | 相对放松姿态 −1.2 至 +0.6 rad，无独立轴向扭转自由度 |
| 拇指根部 | 独立的较宽张合包络 ±35°、屈伸 −1.1 至 +0.8 rad；不是完整的拇指解剖模型 |

中间两节保留自然弯曲，主要由指根和腕部运动。先将 IK 请求投影到关节允许的自由度，再限制参数路径的角速度；中末节是一维铰链，指根是有界的屈伸与张合两轴模型。预览从各指的中立骨架平面推导局部轴，支持镜像手和非默认手型；Blender 使用已支持骨架的局部 X 弯曲轴、Z 张合轴，并相对放松参考姿态求解。范围是保守动画参数，尚未用人体采集数据标定。

关节插值在受限角度参数上进行，不能用普通四元数球面插值把指根带离两轴曲面。两轴正交时参数速度的欧氏范数等于该路径的旋转速度，因此整个过渡都服从原来的 8/1.5 rad/s 上限；中末节总偏离也仍不超过 0.20 rad。腕部继续用原有四元数限速。骨架预览以固定骨长的正向运动学重建，不能靠伸长骨段去追触点。

预览按 60 Hz 固定时间轴求解并插值，随机拖动与顺序播放得到相同结果。热点缓存最多 120 个状态，每秒保存一个检查点；首次跳到后段需要补算历史，后续附近播放复用缓存。修改动作、姿态或更换工程会清空历史。

Blender 在接触拟合和避碰之后约束实际求解的关节局部旋转，关闭当前采样的 IK 后输出受限姿态。下一采样重新启用需要的接触 IK。腕部限速针对解剖腕点而非模型物体原点，旋转不能绕原点带走腕点。最后重新测量蒙皮触点误差与碰撞；不再通过拟合回写覆盖硬限制。旧 `render_speed_limits=False` 也不能关闭此限制。

支持的 Blender 骨架把弯曲和张合烘焙为 XYZ 欧拉角通道，局部 Y 不引入额外扭转，中末节的 Z 保持参考值。线性插值这些通道可保留自由度与角度范围，避免四元数分量插值在中间帧重新引入扭转。新检查结果记录 `anatomy_model=hinge_and_bounded_mcp_v1`；旧工程不重写动作，但旧手部证明会在问题列表中标为模型过期。

限速后够不到的触点必须保留误差。预览显示“运动约束后触点偏差”，Blender 在 `diagnostics.json` 中保留实际蒙皮误差以及 `motion_stats` 的腕速、关节角速、活动幅度与截断次数。触控文件判定合法不代表受限的手模型能够完成该指法；这一层不会自动重新分配手指，也不保证无穿模。

验证：`python -m unittest discover -s tests`。`tests/test_hand_limits.py` 覆盖短间隔/竖直位移硬限速、半周旋转、关节幅度与速度、固定骨长、随机跳转一致性、不可达提示和姿态变更后的缓存失效。

2026-10-20 本机验证：77 项测试通过，完整编译检查通过。对用户已有 70min 工程的 71–77 秒按 240 Hz 采样，腕速峰值从 19.11396 m/s 限为 0.9 m/s；指根峰值 8 rad/s、中末节峰值 1.5 rad/s、中末节偏离自然姿态峰值 0.2 rad。受限后的触点偏差最高约 108.6 mm，说明现有指法仍需重规划，不能将触控覆盖通过误称为手模型可演奏。首次跳转到该段补算约 8 秒，后续附近播放复用缓存。本机没有 Blender/手部模型，Blender 端尚未做实际蒙皮烘焙验证。

2026-10-21 新增方向约束验证：Cthugha AT 四指已有初稿的 1272 段动作，在 12709 个采样时刻及内部事件步长复核。非允许方向的旋转残差由原模型最高 1.453 rad 降为零（该残差同时包含指根越界，不能解释为中节侧弯了 1.453 rad）；指根张合越界由最高 1.589 rad 降为浮点误差量级。腕速、腕角速、指根角速、中末节角速与末节总幅度均保持原上限。旧动作最高命中偏差仍有 57.93 mm，属于待重规划的旧打法，不能宣称可演奏。审计约 91 秒，包含完整复核开销，不是整曲重新生成耗时；原工程内容未修改。

已在 Blender 4.5.3 中加载实际 `MOD-FlowPhi.blend`，验证 30 个骨骼的烘焙及 891 个中间帧，最大自由度残差约 1.02e-7 rad（浮点精度量级）。这验证的是关节与动画曲线，不等于全曲蒙皮无穿模。见 `tests/blender_joint_anatomy_contract.py`、`.local/anatomy-blender-contract.log` 和 `.local/cthugha-anatomy-verification.json`。新增测试覆盖双手各指单轴、指根限幅、旋转后的局部轴、非单位参考姿态、过渡中的限速和实际预览关节位置、旧证明失效。

最终完整 177 项回归测试通过（198.823 秒），新增关节方向与证明失效检查均通过；编译与差异格式检查通过。此轮验证复用 Cthugha 已有动作，没有从空动作重新生成整曲，也没有覆盖用户工程。
